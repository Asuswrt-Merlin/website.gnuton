About the project

One goal: more Merlin routers.

A community firmware fork that brings the Asuswrt-Merlin experience to additional ASUS models — without forking the feature set or hiding the build process.

Why this fork exists

This is an official Merlin forksupported by ASUS andRMerlin. Its aim is straightforward: make Merlin run on additional routers.

The builds are intended to support every feature present in the original Merlin firmware. Occasionally the project also adds functionality for specific models. There is no separate ecosystem to learn and no reduced “community edition” — the upstream firmware is the foundation.

Images are compiled in the cloud so the process stays transparent. Some ASUS-supplied vendor components remain prebuilt, while the project source and build definitions are publicly available in theGitHub repository. When a build is released, you can trace what went into it.

The short version

  • Official Asuswrt-Merlin fork
  • Supported by ASUS and RMerlin
  • 13 builds across 3 WiFi generations
  • WiFi 7, WiFi 6 and WiFi 5 models
  • Cloud-built release images

How the project works

What stays constant

01

Upstream first

Every build starts from the official Asuswrt-Merlin source. GNUton adds model support, not a parallel feature set — if it is in Merlin, it should be here.

02

Transparent builds

Images are compiled in the cloud through a public build pipeline. Some vendor components supplied by ASUS remain prebuilt, but releases stay traceable to their build run and source history.

03

Community tested

Beta builds go out to testers before they become stable. Bug reports, forum threads and chat feedback are part of the release process.
