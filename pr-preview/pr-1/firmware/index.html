Release channels

Stable, beta, or experimental

Use stable for everyday routing. Try pre-releases when you can test and report back. Experimental builds exist for specific features.

Recommended

Stable

Recommended for everyday use. Promoted from beta once the branch has had real-world testing.

Browse stable builds

Pre-release

For advanced users and testing new features. Read the release notes before flashing a beta.

Browse pre-releases

Experimental

One-off branches that explore extra functionality, such as Repeater Mode on the 386 DSL build.

Browse experimental builds
AiMesh or Repeater? Standard images already support AiMesh, which is faster when both ends are ASUS routers. Repeater Mode is only available through the experimental 386 build listed above.
