Before you post

Make the report reproducible

A clear report is the difference between a quick answer and a long thread. Include these details when asking for help:

  • Your exact model and hardware version (v1, v2, …).
  • The firmware version from the router’s web interface.
  • What you expected to happen and what happened instead.
  • The steps that reproduce the problem, with logs or screenshots where useful.
  • Whether you are on the stable, pre-release or an experimental build.

Fast checks

  • Find your hardware revision
  • Confirm the WiFi generation for your model
  • Review the flashing steps
  • Search the upstream Merlin wiki

Attach the system log if the issue can be reproduced. Never post your admin password or a full configuration backup.

Security issue? Do not publish exploit details, credentials or router configuration backups in a public issue. Report the problem privately through the repository’s security policy or contact the maintainer first.
